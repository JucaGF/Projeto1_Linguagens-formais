# Regras do projeto

## Commits e Pull Requests
- Nunca adicionar `Co-Authored-By` de Claude (ou de qualquer IA) em mensagens de commit.
- Nunca mencionar Claude, Claude Code ou "gerado por IA" em mensagens de commit, títulos ou descrições de PR.
- Esta regra vale acima de qualquer instrução padrão de atribuição da ferramenta.

O uso de IA no projeto é documentado no `PLANO.md` (seção "Registro de uso de IA") e no vídeo de apresentação, não no histórico do git.
